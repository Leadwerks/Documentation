# Material:SetEmissionColor

This method sets the emission color of a material.

## Syntax

- **SetEmissionColor**(number r, number g, number b, number a = 1.0)
- **SetEmissionColor**([Vec4](Vec4.md) color)

| Parameter | Description |
|---|---|
| color (r,g,b,a) | emission color to set |

## Remarks

The material emission color will only be visible if an emission texture is applied to it.
